머신러닝 분석 프로세스와 확인/분할/전처리 과정 

(1) 머신러닝 분석 프로세스를 알아보자
(2) 데이터 확인/분할/전처리 과정을 알아보자
(3) 모델 학습 및 성능평가 과정을 알아보자

 머신러닝 분석 프로세스는 주어진 데이터로부터 독립변수와 종속변수의 관계를 학습하여 이를 바탕으로 예측을 수행하는 일련의 과정
 머신러닝 분석 프로세스: 데이터 확인 ➔ 전처리 ➔ 데이터 분할 ➔ 모델 학습 ➔ 성능 평가 

예) 독립변수 X= 환자의 증상 종속변수 Y = 질병의 발병 여부 간의 관계를 학습
     새로운 환자의 질병 발병 여부를 예측하기 위한 모델을 개발하는 과정

1) 데이터확인 : 분석 대상이 되는 데이터의 특성을 파악하는 단계
 — 독립변수와 종속 변수의 존재 여부를 파악
 — 적용가능한 분석 모델을 확인 
 — 종속변수가 연속형일 경우 주로 회귀모델을 사용 
 — 범주형일 경우 분류 모델을 사용 
 — 종속변수가 없는 경우 주어진 데이터 자체에서 패턴, 구조, 관계 등을 파악하기 위해 비지도 학습을 사용 

2) 전처리 : 데이터 모델 학습에 적합한 형태로 변환하는 과정 
 — 데이터를 모델 학습에 적합한 형태로 변환하는 과정 

 — 표준화, 정규화 : 모든 특성을 동일한 중요도로 처리하기 위한 과정  
 — 표준화 : 데이터가 평균 0, 표준편차 1 을 가지도록 변환 
 — 정규화 : 데이터의 범위를 [0,1] 또는 [-1,1]로 조정하는 것
 — 결측치 : 일부 정보가 누락된 경우, 특정값으로 대체하거나 결측치가 있는 행 또는 열을 삭제 
 — 이상치 : 측정 오류나 다른 이유로 인한 극단적인 값, 통계적 방법으로 탐지하고, 삭제하거나 대체하여 처리 

 의료 데이터의 특성상, 환자 정보가 다양한 척도(나이, 키, 체중 등)로 표현되며 결측치나 이상치가 흔히 발생하는데, 이러한 특성을 고려하여 각 척도에 적합한 전처리 방법을 적용하는 것이 중요하며, 이 과정은 향후 모델의 예측 성능에 결정적인 영향을 미친다. 

3) 데이터 분할
 인공지능 모델을 개발하기 위해서는 데이터를 Train, Validation, Test 3가지 data set로 분할해야 함 # — Train data = 모델이 처음 보는 패턴과 관계를 학습하기 위해 사용하는 데이터 셋으로 전체 데이터셋의 약 60%~80%를 차지함 # — Validation data는 학습 도중 모델의 성능을 검증하기 위해 사용하는 데이터 셋으로 모델의 과적합을 방지하여 최적의 하이퍼파라미터를 찾는 데 도움을 줌. 전체 데이터셋의 10%~20% 차지
 — Test data는 모델 학습과 검증이 완료된 후, 최종적으로 모델의 성능을 평가하는 데 사용. 이 단계에서는 모델이 실제로 알려지지 않은 데이터에 대해 얼마나 잘 예측하는지 평가하며, 전체 데이터셋의 약 10%~20%를 차지 
 — 데이터 분할 시 모델의 성능 강화 및 과적합 방지를 위해 교차 검증방법을 적용할 수 있다. 

  (1) 교차 검증: 데이터를 여러 부분으로 나눠 각각을 학습과 테스트에 반복적으로 사용하는 방법
     - 대표적으로 K-fold 교차 검증이 있다.
4) 지도/비지도학습의 개념과 대표적인 모델 

  (1) 대표적인 지도학습(회귀모델)의 개념 및 설명
     — LinearRegression : 독립변수와 종속변수 사이의 선형관계를 모델링하여 연속형 종속변수를 예측
     — Polynomial Regression : 독립변수의 고차항을 포함하여 비선형 관계를 모델링하여, 연속형 종속 변수를 예측하는 기법 
     — SVM : 마진을 최대화하여 결정 경계를 찾는 알고리즘으로, 선형 뿐만 아니라 비선형 문제에도 적용가능
     — Random Forest : 여러개의 decision tree를 학습한 후 결과를 집계하여 최종 예측을 하는 알고리즘으로 오버피팅을 줄이고 일반화 성능을 향상시킴
     — XGBoost : Gradient Boosting 알고리즘을 최적화한 형태로, 고차원 및 희소 데이터에 대해 뛰어난 성능을 보임 

  (2) 대표적인 비지도 모델의 개념 및 설명 
     — K-means Clustering : 데이터를 K개의 클러스터로 그룹화하는 비지도 학습 알고리즘, 중심점과의 거리를 최소화하며 클러스터를 형성함 

5) 성능평가
  — 성능평가는 학습된 모델의 예측 성능을 검증 데이터를 이용하여 평가하는 과정으로 모델의 신뢰성을 평가 
  — 성능평가 기법은 모델의 유형에 따라 다르며, 회귀모델의 대표적인 성능평가 방법: MAE, MSE, R2 score  
  — 분류모델의 대표적인 성능평가방법: Confusion Matrix, Accuracy, Precision, Recall, f1 score, ROC curve
