 데이터 분할의 목적
머신러닝 모델은 보지 않은 데이터에 대해 얼마나 잘 예측하는지를 평가해야 하는데, 
이를 위해 전체 데이터를 훈련(Train), 검증(Validation), 테스트(Test) 세 집합으로 나눈다.

  1) Train set : 모델이 패턴을 학습하는데 사용하는 데이터 
                 실제로 파라미터(가중치)를 업데이트 하는데 사용
                 전체 데이터의 70-80%
  2) Valid set : 훈련 중간에 모델의 성능을 평가하고, 하이퍼파라미터를 조정
                 모델이 훈련에만 과하게 맞춰지는지(과적합)을 확인
                 전체 데이터의 10-15%
  3) Test set : 학습이 완료된 후, 최종적으로 모델의 성능을 평가하는 데 사용
                모델이 훈련이나 검증 중에 전혀 보지 않았던 완전히 새로운 데이터
                실제 환경에서의 예측 성능을 추정하기위해 사용하며, 약 10-15%를 배정 


[요약정리]          Train
                목적: 모델 학습
                특성: 가중치 조정용
                
                  Validation
                목적: 성능 확인·튜닝
                특성: 하이퍼파라미터 조정
                
                  Test
                목적: 최종 평가
                특성: 완전히 독립된 데이터

--------------------------- 하이퍼파라미터 | 설명 -----------------------------
test_size : float or int, default=None | test set의 비율, default값 = 0.25
shuffle : default=True                 | data를 섞을지 여부, default = True
stratify : array-like, default=None    | stratify는 데이터를 분할할 때 클래스 분포를 유지하기 위한 옵션(분류(classification) 문제에서 주로 사용)
                                         stratify를 사용하면 데이터를 나눌 때 각 클래스의 비율을 유지하도록 보장가능하며, 데이터가 불균형한 클래스 분포를 가지고 있을 때 유용함
random_state : int                     | 난수 생성 시드(seed), 데이터를 무작위로 섞을 때 사용되는 난수 생성 알고리즘의 초기값을 뜻함
                                         초기값을 설정하면 데이터를 무작위로 섞을 때 매번 같은 순서로 섞이게 됨
** shuffle 이 False로 설정되었다면 stratify 역시 디폴트 값인 None으로 설정 되어야 한다.
